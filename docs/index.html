NotifyHub

One API. Every channel.

Unified notification library for Java and Spring Boot.
Send via Email, SMS, Slack, Discord, Telegram, Teams, WhatsApp, Google Chat, Push, WebSocket — with one fluent API.

GitHub Maven Central

Quick Start

pom.xml
<dependency>
    <groupId>io.github.gabrielbbaldez</groupId>
    <artifactId>notify-spring-boot-starter</artifactId>
    <version>0.6.0</version>
</dependency>
<dependency>
    <groupId>io.github.gabrielbbaldez</groupId>
    <artifactId>notify-email</artifactId>
    <version>0.6.0</version>
</dependency>
Java
@Autowired NotifyHub notify;

notify.to("user@example.com")
    .via(Channel.EMAIL)
    .fallback(Channel.SMS)
    .subject("Order Confirmed")
    .template("order-confirmed")
    .param("orderId", "ORD-2024")
    .send();

Features

11+

Channels

Email, SMS, WhatsApp, Slack, Telegram, Discord, Teams, Google Chat, Push, WebSocket, Webhooks

⚙

Fluent API

Builder pattern with chaining: .to().via().fallback().template().send()

🔄

Fallback Chains

If email fails, try SMS. If SMS fails, try Slack. Automatic failover.

📋

Templates

Mustache HTML templates with i18n, versioning, and dynamic params.

👥

Batch Send

Send to thousands of recipients with toAll() and failure isolation.

⏳

Scheduling

Schedule for later: .schedule(Duration.ofMinutes(30)) or at a specific time.

🔁

Retry & DLQ

Exponential/fixed backoff with dead letter queue for exhausted retries.

📈

Rate Limiting

Per-channel token bucket. URGENT priority bypasses limits.

🔍

Delivery Tracking

DeliveryReceipt with status, timestamp. In-memory or JPA persistence.

🤖

MCP Server

13 tools for AI assistants (Claude, etc.) via Model Context Protocol.

🚀

REST API

Docker image with Swagger UI. Just set env vars and call endpoints.

🌐

Admin Dashboard

Web UI for monitoring channels, tracking, and dead letter queue.

Docker

Run NotifyHub instantly with Docker — no Java required. Two images available: a REST API with Swagger UI for any language/platform, and an MCP Server for AI assistants like Claude.

📋

REST API

gabrielbbal10/notifyhub-api

Full REST API with Swagger UI on port 8080. Send notifications via HTTP from any language — Python, Node.js, Go, cURL, etc. Just set environment variables for the channels you want and hit the endpoints.

Docker Hub Docs
Quick Start — Email + Discord
docker run -d -p 8080:8080 \
  -e NOTIFY_CHANNELS_EMAIL_USERNAME=you@gmail.com \
  -e NOTIFY_CHANNELS_EMAIL_PASSWORD=your-app-password \
  -e NOTIFY_CHANNELS_EMAIL_FROM=you@gmail.com \
  -e NOTIFY_CHANNELS_DISCORD_WEBHOOK_URL="https://discord.com/api/webhooks/..." \
  -e NOTIFY_CHANNELS_DISCORD_USERNAME="NotifyHub" \
  gabrielbbal10/notifyhub-api:latest
Then call the API
# Send email
curl -X POST "http://localhost:8080/send/email?to=user@example.com&subject=Hello&body=Hi!"

# Send Discord message
curl -X POST "http://localhost:8080/send/discord?message=Deploy done!"

# Swagger UI
open http://localhost:8080/swagger-ui.html

MCP Server

gabrielbbal10/notifyhub-mcp

Model Context Protocol server with 13 tools for AI assistants. Connect Claude Desktop, Claude Code, or any MCP-compatible client and let AI send notifications on your behalf.

        "-e", "NOTIFY_CHANNELS_EMAIL_USERNAME=you@gmail.com",
